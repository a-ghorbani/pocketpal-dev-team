### Background

Ukrainian (uk) and Chinese Traditional (zh_Hant) translations are 100% complete on Weblate after PR #647. These languages need to be wired into the app so users can select them from the Settings language picker.

- `zh_Hant.json` already exists in `src/locales/` on main
- `uk.json` exists only on the `origin/weblate-translations` branch (PR #647 not yet merged) and must be copied into the worktree

### Current State
- `src/locales/index.ts` registers 9 languages: en, fa, he, id, ja, ko, ms, ru, zh
- Both JSON files exist (zh_Hant on disk, uk on weblate branch) but are not wired into the app
- E2E language test covers the 9 existing languages

### Target State
- 11 languages registered: en, fa, he, id, ja, ko, ms, ru, uk, zh, zh_Hant
- Users can select Ukrainian and Chinese Traditional from Settings
- All tests and validation scripts account for the new languages
