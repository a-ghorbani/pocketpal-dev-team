### Background
llama.rn is the core native dependency that provides on-device LLM inference via llama.cpp. Keeping it up to date brings performance improvements, bug fixes, and new capabilities. Version 0.12.0-rc.2 includes:
- Reasoning budget support (new additive feature)
- llama.cpp synced to b8547
- Antiprompt/sampling rewind fix
- `force_pure_content` support (new additive feature)
- TTS vocoder fix
- TranslateGemma fix

### Current State
- `package.json`: `"llama.rn": "0.11.5"`
- `ios/Podfile.lock`: `llama-rn (0.11.5)`
- `yarn.lock`: corresponding lockfile entries for 0.11.5
- All llama.rn imports in `src/` use: `LlamaContext`, `initLlama`, `ContextParams`, `CompletionParams`, `loadLlamaModelInfo`, `JinjaFormattedChatResult`, `TokenData`, `BuildInfo`, `getBackendDevicesInfo`, `NativeBackendDeviceInfo`
- None of these APIs are removed or changed in 0.12.0

### Target State
- `package.json`: `"llama.rn": "0.12.0-rc.2"`
- `ios/Podfile.lock`: updated to reflect 0.12.0-rc.2
- `yarn.lock`: updated lockfile entries
- All existing functionality continues to work
- New features (reasoning_budget, force_pure_content) are available but not yet used
