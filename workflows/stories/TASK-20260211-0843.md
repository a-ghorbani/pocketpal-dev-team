### Background

llama.rn is PocketPal's native bridge to llama.cpp, the underlying LLM inference engine. PocketPal currently uses version `0.11.0-rc.4` (release candidate). The stable `0.11.0` release is now available on npm and should be adopted to move off the release candidate track.

This is a low-risk upgrade: the orchestrator confirmed zero TypeScript API changes by diffing `.d.ts` files between rc.4 and 0.11.0 stable. The only notable internal changes are:
- C++ header rename: `llama-sampling.h` to `llama-sampler.h` (PocketPal does NOT reference this directly)
- Android `CMakeLists.txt` fix for unsupported ABIs
- llama.cpp build bumped from b7951 to b7992

### Current State

**Current version**: `llama.rn@0.11.0-rc.4` (set in `package.json` line 50)

Files referencing llama.rn:
- **22 source files** in `src/` (types, utils, stores, components, hooks, screens)
- **2 mock files** (`__mocks__/external/llama.rn.ts`, `__mocks__/stores/modelStore.ts`)
- **3 iOS files** (`ios/Podfile.lock`, `ios/PocketPal/AppIntents/LlamaInferenceEngine.swift`, `ios/PocketPal-Bridging-Header.h`)
