## Context (For Recovery After Context Reset)

### Background
TestFlight build 1.13.1 (build 134) crashes on launch for an iPhone 16 Pro Max user running iOS 18.4. Two crash reports show EXC_CRASH (SIGABRT) in `ObjCTurboModule::performVoidMethodInvocation`, traced to `react-native-keyboard-controller` v1.19.1. The `KeyboardProvider` component (wrapping the entire app in `App.tsx`) calls `preload()` on startup, which creates a hidden UITextField and calls `becomeFirstResponder`/`resignFirstResponder`. Two bugs in this flow were fixed upstream:

1. **Preload tracking view crash** - fixed in v1.19.2 (upstream PR #1170)
2. **ensureLayout NSException** - fixed in v1.19.3 (upstream PR #1174)

### Current State
- `package.json`: `"react-native-keyboard-controller": "^1.19.1"` (resolved to 1.19.1 in yarn.lock)
- `ios/Podfile.lock`: pinned to `1.19.1`
- 4 source files import from the package (no API changes needed):
  - `App.tsx` — `KeyboardProvider`
  - `src/components/ChatView/ChatView.tsx` — `KeyboardStickyView`, `useReanimatedKeyboardAnimation`
  - `src/components/Dialog/Dialog.tsx` — `KeyboardAwareScrollView`
  - `src/components/Sheet/BottomSheetAwareScrollview.tsx` — `KeyboardAwareScrollView`, `useReanimatedKeyboardAnimation`
- Jest mock: `jest/setup.ts` uses `react-native-keyboard-controller/jest` (built-in mock from the package)

### Target State
- `package.json`: `"react-native-keyboard-controller": "^1.21.3"` (or `"1.21.3"`)
- `yarn.lock`: resolved to 1.21.3
- `ios/Podfile.lock`: updated to 1.21.3
- No source file changes needed — all APIs (`KeyboardProvider`, `KeyboardStickyView`, `useReanimatedKeyboardAnimation`, `KeyboardAwareScrollView`) are unchanged between 1.19.1 and 1.21.3
