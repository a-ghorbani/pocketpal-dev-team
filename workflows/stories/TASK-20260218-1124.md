### Background

Korean (ko), Malay (ms), Russian (ru), and Hebrew (he) translations are all 100% complete on Weblate (882 keys each, matching en.json exactly). PR #569 (`weblate-translations` branch) contains the updated translation files. These languages need to be wired into the app so users can select them from the Settings language picker.

Note: Hebrew is RTL but PocketPal has no RTL layout support yet. Hebrew text will still render correctly (Unicode BiDi algorithm handles character/word ordering), but UI layout (alignment, navigation) will remain LTR. This is acceptable — better than forcing Hebrew speakers to use English.

Since PR #579 (lazy-load l10n, merged), adding a new language is simplified: the `languageRegistry` in `src/locales/index.ts` is the single source of truth. UIStore, SettingsScreen, and the uiStore mock all derive `supportedLanguages` and `AvailableLanguage` type from it automatically.

Additionally, `benchmark.benchmarkResultCard.actions.deleteButton` in en.json is currently `"Delete"` but should be `" "` (intentionally blank — it's an icon-only button). This fix is included in this PR.
