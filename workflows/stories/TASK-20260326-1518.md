### Background
The Cohere tiny-aya model family uses `<|END_RESPONSE|>` as its end-of-generation token. Without this token in the `stops` array, PocketPal will not properly detect when the model has finished generating, causing it to continue past the intended end of output.

### Current State
- File: `src/utils/chat.ts:312-324` — The `stops` array contains 10 stop tokens covering various model families (Llama, GPT, Phi, Gemma, etc.)
- The last entry is `'<|return|>'` with the comment `// gpt-oss` at line 323
- File: `src/store/ModelStore.ts:2348-2357` — `stops` is imported and filtered against chat/context templates to determine which stop tokens are relevant for the loaded model

### Target State
- The `stops` array includes `'<|END_RESPONSE|>'` as a new entry after the `gpt-oss` line, enabling proper stop detection for Cohere tiny-aya models
