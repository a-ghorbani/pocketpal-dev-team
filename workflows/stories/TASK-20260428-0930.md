## Background

PocketPal currently has multiple review definitions across Claude and OpenCode.
That creates drift risk as review expectations evolve.

## Current State

- Claude has pipeline-specific reviewer prompts in `.claude/agents/` and a PR
  review skill in `.claude/skills/review-pr/`.
- OpenCode has persona-specific reviewer prompts in `.opencode/agents/`.
- `tools/code-review.sh` already treats review as a shared workflow with thin
  persona adapters.

## Target State

- One shared review standard captures the durable PocketPal review contract.
- Codex gets two reviewer adapters:
  - a comprehensive reviewer for deep human-facing review
  - a headless reviewer for agent-to-agent delegation and automation
- Tool-specific wrappers stay thin and can reference the shared standard.
