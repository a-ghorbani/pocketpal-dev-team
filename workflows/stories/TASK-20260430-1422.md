## Context

Codex should rely on its sandbox and approval configuration for normal worktree development instead of custom per-command allow rules. Hooks should stay focused on denying the few repo-specific operations that must never happen.

## Requirements

1. Configure Codex to run normal reads, edits, creates, directory creation, builds, tests, device tooling, and other shell commands without per-command prompts inside the workspace sandbox.
2. Keep sensitive paths blocked everywhere, including inside `worktrees/`.
3. Keep `repos/pocketpal-ai/` protected from direct mutation.
4. Keep custom hooks deny-only so policy remains understandable.
